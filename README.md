# Premium JavaScript Calculator 🧮✨

A beautiful, high-end JavaScript calculator featuring a breathtaking "Aurora Borealis" dark mode UI with interactive glowing neon elements.

## Features
- **Aurora Borealis Background**: Mesmerizing animated mesh gradient.
- **Glassmorphism UI**: Beautiful frosted dark glass aesthetic.
- **Neon Glow Interactions**: Satisfying spring animations with RGB glowing hover effects.
- **Full Keyboard Support**: Type naturally with your numpad or keyboard.
- **Precision Math**: Built-in fixes for standard floating-point precision issues.

## How to run
Simply open `index.html` in your favorite browser, or run a local server:
```bash
npx http-server
```
